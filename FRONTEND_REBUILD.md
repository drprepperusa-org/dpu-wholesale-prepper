# Frontend Rebuild Plan

## Problem
Current Vue app is basic and doesn't match the HTML design provided. Need to rebuild to match the target design exactly.

## Target HTML Features
1. **Top Navigation** - Brand, burger menu, tabs (Order/Favorites/History), cart button, account dropdown
2. **Sidebar** - Category search, category list with counts
3. **Main Content** - Product grid with favorites, search, sorting
4. **Product Cards** - Image, name, details, buttons, in-cart state, qty pill
5. **Product Detail Modal** - Sheet overlay with product info, unit selection, qty controls
6. **Cart Drawer** - Item list, subtotal, place order button
7. **Order History** - Order cards with expandable details
8. **Account Settings Modal** - Profile, contact, security tabs
9. **Responsive Design** - Mobile-optimized layout

## Implementation Steps
1. Rebuild App.vue with complete HTML structure
2. Create necessary Vue components for each section
3. Build and verify the design matches HTML
4. Deploy to public directory
5. Test on live site

## Timeline
- Rebuild core layout: 15 min
- Create components: 20 min
- Styling and responsive: 15 min
- Build and deploy: 5 min
